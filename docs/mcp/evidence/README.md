# MCP external-validation evidence

No live OIDC output and no MCP Playground screenshots are stored here.

Add redacted files only after the procedures in `docs/mcp/oidc-validation.md` and `docs/mcp/playground-validation.md` are actually run. Do not commit access tokens, staff tokens, or `Authorization` headers. A file in this directory is not evidence until it shows a real issuer response or the public `*.app.github.dev/mcp` URL.
